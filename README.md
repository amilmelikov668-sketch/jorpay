# Kilo

Kilo — облегчённая социальная сеть в стиле Telegram: создавайте пользователей, собирайте их в чаты и обменивйтесь сообщениями через простой REST API на FastAPI.

## Быстрый старт
1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
2. Запустите сервер:
   ```bash
   uvicorn kilo.app:app --reload
   ```
3. Откройте интерактивную документацию по адресу http://127.0.0.1:8000/docs.

## Основные эндпоинты
- `POST /users` — создать пользователя (username и отображаемое имя).
- `POST /chats` — создать чат с набором участников.
- `GET /chats/{chat_id}` — получить данные чата.
- `POST /chats/{chat_id}/messages` — отправить сообщение от участника.
- `GET /chats/{chat_id}/messages` — получить историю сообщений чата.

Хранилище в памяти облегчает экспериментирование и прототипирование. Добавьте постоянное хранилище и авторизацию, чтобы развить Kilo до полноценного мессенджера.
